# atividade-da-aula-08-
API REST em Node.js com Express e ORM Prisma para gestão de alunos, cobrindo rotas HTTP (POST/GET). O foco do projeto é a suíte de testes automatizados com Vitest e Supertest, aplicando testes unitários e de integração de rotas com mocks (vi.mock) para isolar a regra de negócio do banco de dados de forma rápida, confiável e independente.
